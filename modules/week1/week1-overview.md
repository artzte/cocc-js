## Overview of Week 1: What is JavaScript

The readings this week are somewhat wonky; I am sure you have heard of JavaScript, and know that it
is a programming language that works in the browser. But there is a bit of context that will be
helpful in your longer journey understanding the language, its environments, and history, that will
be helpful to you in your journey.

### Module Objectives

By the end of this module you will be able to:

- Describe what JavaScript is, exactly
- Describe how JavaScript maintains backward compatibility while incorporating new features
- Build your weekly projects

### Steps to Complete

1. Complete the reading assignment: YDKJS(y): Getting Started / Chapter 1
2. Complete the setup steps for the software you'll need to work through the assignments for the
   course
3. Submit your first weekly project.
