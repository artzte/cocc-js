## Course Description

Learn programming fundamentals and object-oriented concepts using vanilla JavaScript syntax. Add
interactivity and custom behaviors to web applications by employing front-end JavaScript techniques
combined with HTML and CSS.

## Learning Outcomes

1. Implement scripts that rely on knowledge of Document Object Model (DOM) architecture and includes
   methods for manipulating DOM objects.
2. Construct functions that effectively utilize variables, conditionals, loops, and arrays.
3. Generate scripts that process user input and provide meaningful output.
4. Plan and create scripts utilizing events and event handlers that respond to user inputs.

## Class Topics and Schedule

- **Week 1 — What Is JavaScript?** — JS engines, runtimes, strict mode, DevTools; dev environment
  setup; write your first test
- **Week 2 — Values, Types, and Variables** — Primitive types, strings, numbers,
  `let`/`const`/`var`, `typeof`; select and update DOM elements
- **Week 3 — Functions and Comparisons** — Function syntax forms, parameters, return values; strict
  vs. loose equality, truthy/falsy, conditionals
- **Week 4 — Arrays, Loops, and Iteration** — Array methods, `for`/`while`/`for...of`, higher-order
  methods (`map`, `filter`, `reduce`); _Project Milestone 1 (Proposal) due_
- **Week 5 — Lexical Scope** — How JS compiles before executing, lexical scope model, scope nesting,
  variable lookup
- **Week 6 — Scope Chain, Global Scope, and Variable Lifecycle** — Scope chain, shadowing, global
  scope in the browser, hoisting, Temporal Dead Zone
- **Week 7 — Closures** — Principle of Least Exposure, closure mechanics, factory functions,
  stateful encapsulation; _Project Milestone 2 (Design Document) due_
- **Week 8 — Classes and OOP** — ES6 `class` syntax, `this` binding, inheritance with
  `extends`/`super`, static members
- **Week 9 — Modules** — ES Modules (`import`/`export`), module scope, Vite and ESM, `localStorage`
  persistence; _Project Milestone 3 (Initial Structure) due_
- **Week 10 — Events and the DOM** — Event bubbling/capturing, `addEventListener`, event delegation,
  form events
- **Week 11 — Async JavaScript** — Event loop, Promises, `async`/`await`, `fetch`, error and loading
  state handling
- **Week 12 — Final Project** — Demo, code review, deployment; _Project Milestone 4 (Final
  Submission) due_

## Grading and Assignments

### Grading Standard

I am committed to your success in this course. For your part, I encourage you to keep up with the
weekly quizzes and assignments, and communicate with me if you need assistance at any time. I will
accept, and will not penalize, late work (up until exam week), but it has been my experience that
students who get behind in these courses have great difficulty catching up.

- Weekly quizzes: 20%
- Weekly assignments: 40%
- Final project (divided into four equal deliverables): 40%

### Help on Assignments

I encourage you to use Github CoPilot to review your pull requests prior to submitting. Beyond that,
you should not be getting help on your assignments from classmates or coding agents. Please reach
out to me if you need help with your assignments.

### Artificial Intelligence Policy

Students may not use GenAI tools in this course to produce course materials or assignments in whole
or in part. All work you submit for this course toward completion of course requirements must be
your own original work done specifically for this course and without substantive assistance from
others, including GenAI. Work you've completed for previous courses or are developing for other
courses this term also should not be submitted for this course.
